TIMEZONE_FIX.PY requirements:

The goal is to ensure all daily candles in the database close at NY close (5:00 PM Eastern Time), not midnight UTC or any other time. This is critical for zone detection consistency.

The problem: Dukascopy data may use UTC midnight as the day boundary, which creates a Sunday stub candle issue and misaligns with the NY close candles that Nick uses on TradingView.

The solution to implement:

1. Function detect_candle_close_convention(df) that:
   - Examines the date sequence in a DataFrame
   - Detects if there are Sunday dates present (indicates midnight UTC convention)
   - Returns 'NY_CLOSE', 'UTC_MIDNIGHT', or 'UNKNOWN'

2. Function fix_timezone_to_ny_close(pair, df) that:
   For data using UTC midnight convention:
   - Each "date" in UTC midnight data actually represents the candle starting at 00:00 UTC
   - The 5PM EST candle = candle starting at 22:00 UTC previous day (winter) or 21:00 UTC (summer)
   - SIMPLEST CORRECT APPROACH: if Sunday stubs exist, merge Sunday data into Monday (extend Monday's high/low to include Sunday's range, use Sunday's open as Monday's open, keep Monday's close) and drop the Sunday row
   - Shift remaining dates forward by 1 day where needed to align with the correct NY close date label
   - Use the US DST schedule to determine the offset: second Sunday of March through first Sunday of November = EDT (UTC-4, NY close = 21:00 UTC). All other periods = EST (UTC-5, NY close = 22:00 UTC).

3. Function remove_sunday_stubs(df) that:
   - Identifies Sunday dates in the dataframe
   - For each Sunday, finds the following Monday
   - Merges the Sunday bar into Monday: Monday.open = Sunday.open, Monday.high = max(Sunday.high, Monday.high), Monday.low = min(Sunday.low, Monday.low), Monday.close stays as Monday.close, Monday.tick_volume += Sunday.tick_volume
   - Drops the Sunday row entirely
   - Returns the cleaned dataframe

4. Main function: normalize_pair_timezone(pair, df) → returns cleaned df with correct NY close dates

CLEAN.PY requirements:

1. Function compute_atr(df, period) that computes ATR using pandas EWM directly (NOT using any TA library):
   - True Range = max(High-Low, |High-PrevClose|, |Low-PrevClose|)
   - Compute True Range as a pandas Series using: pd.concat([high-low, (high-prev_close).abs(), (low-prev_close).abs()], axis=1).max(axis=1)
   - ATR = true_range.ewm(alpha=1/period, adjust=False).mean()
   - For the first {period} bars where there isn't enough history, fall back to simple mean of available True Range values
   - Return the ATR as a pandas Series aligned with df.index
   - Do NOT use ta.volatility.AverageTrueRange or any TA library function for this — compute it manually as specified

2. Function detect_anomalies(pair, df) that:
   - Marks KNOWN_ANOMALY_EVENTS from config.py as is_anomaly=1 first
   - Then marks any remaining bar where (high - low) > ANOMALY_ATR_MULTIPLE × atr_14 as is_anomaly=1
   - Also marks as anomaly any bar where the open-to-close change exceeds 3 × atr_14
   - Applies a range CAP for anomaly bars: replace their high/low with close ± (ANOMALY_ATR_MULTIPLE × atr_14)
   - Returns df with is_anomaly column populated and ranges capped

3. Function fill_gaps(pair, df) that:
   - Computes the expected sequence of business days between the first and last date in df

   - For any expected business day not present in df, inserts a forward-filled bar: open = high = low = close = previous_close, tick_volume = 0, is_gap = 1
   - Returns df with gaps filled, sorted by date

4. Function normalize_tick_volume(pair, df) that:
   - Computes z-score of tick_volume for this pair: (tick_volume - mean) / std
   - Stores result in tick_vol_zscore column
   - Handles zero-volume bars (is_gap=1) by setting their zscore to -3.0

2. Key Technical Concepts:

- **Wilder ATR via manual EWM** — alpha=1/period, expanding simple mean warmup for first `period` bars, then Wilder EWM seeded by warmup mean. No TA library. Used in clean.py and incrementally extended in pipeline.py's `_atr_incremental()`
- **ATR incremental extension** — for weekly updates, extends Wilder EWM from last known seed values: `p14 = p14*(1-1/14) + tr*1/14` per bar. Avoids reprocessing full history. Only applied to real (non-gap) bars; gap bars get ATR forward-filled.
- **Dukascopy UTC-midnight convention** — Sunday stubs (2hr, merged into Monday) and Saturday stubs (dropped). `_to_api_symbol()` converts EURUSD to EUR/USD for the API.
- **SQLite WAL mode** with ON CONFLICT DO UPDATE upsert pattern. `insert_ohlcv_batch()` refreshes pair_metadata, but the subsequent weekend-row DELETE required a second explicit metadata refresh.
- **Train/val/test split** — train <= 2019-12-31, val <= 2022-12-31, test >= 2023-01-01. Locked; test set never touched during development.
- **CustomBusinessDay gap filling** — uses `pandas.tseries.offsets.CustomBusinessDay` with New Year's + Christmas holidays; `pd.date_range()` to generate expected date sequence.
- **Tick-volume z-score** — computed from non-gap bars only; gap bars assigned -3.0. For weekly updates, uses existing population mu/sigma from DB to keep z-scores comparable.
- **Anomaly detection** — KNOWN_ANOMALY_EVENTS hard-coded (SNB 2015, GBP flash crash 2016, JPY flash crash 2019), plus range > 5xATR-14 and body > 3xATR-14. Flagged bars have high/low capped at close +/- 5xATR-14.
- **`is_gap` invariant** — synthetic gap-fill bars always have `tick_volume=0` AND `is_gap=1`. Any row with `tick_volume > 0` is real Dukascopy data and must have `is_gap=0`.
- **ATR sanity check design** — min/max over 21 years will include GFC/SNB/COVID extremes; only average ATR (20-800 pips) and NULL count are meaningful quality gates.
- **Tee writer pattern** — `_Tee` class mirrors stdout to both terminal and log file simultaneously; used in both validate.py and pipeline.py.
- **JSONL transcript extraction** — Claude Code writes session events to a JSONL file; structure: user messages have top-level `"type":"user"`, assistant messages identified by `message.role=="assistant"`; multiple streaming events share the same `message.id` (take last/most complete); strip `<system-reminder>`, `<ide_opened_file>`, `<ide_selection>` injections from user text.
